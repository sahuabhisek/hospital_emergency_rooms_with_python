🎯 **Project Objective**

The main objective was to analyze hospital emergency room data, identify important operational patterns and generate meaningful insights that can support better data-driven decision-making.

🛠️ **Tools & Technologies Used**

🔹 Python – Data analysis and project development
🔹 Pandas – Data cleaning, manipulation and analysis
🔹 NumPy – Numerical computing library
🔹 Matplotlib – Data visualization
🔹 Seaborn – Statistical data visualization
🔹 Jupyter Notebook – Project development and documentation

📌 **Key Steps Performed in This Project**

**1. Data Understanding**

- Explored the dataset using `head()`, `info()` and `describe()`.
- Checked column names, data types and statistical summaries.
- Identified data-quality issues.

**2. Data Cleaning Using Pandas**

- Checked missing values and missing-value percentages.
- Removed direct patient identifiers from the analysis dataset.
- Standardized gender categories.
- Converted admission flags into readable categories.
- Converted admission dates into datetime format.
- Handled missing department referrals.
- Preserved missing patient satisfaction scores instead of replacing them with misleading values.

**3. Exploratory Data Analysis (EDA)**
Analyzed important business questions:

- What is the total number of emergency room visits?
- What is the average patient waiting time?
- What percentage of patients were admitted?
- Which department received the highest referrals?
- Which month and day had the highest patient visits?
- How does waiting time differ by admission status?
- What is the average patient satisfaction score?
- Which patient age groups have the highest number of visits?

**4. Data Visualization**
Created different visualizations using Matplotlib and Seaborn:

📊 Patient Age Distribution
📊 Emergency Room Waiting Time Distribution
📊 Patient Visits by Gender
📊 Admission Status Analysis
📊 Monthly and Daily Patient Visit Trends
📊 Department Referral Analysis
📊 Admission Rate Analysis
📊 Patient Satisfaction Distribution
📊 Correlation Heatmap

**5. KPI Development**

Created important performance indicators:

- Total Emergency Room Visits
- Average Patient Waiting Time
- Total Admissions
- Admission Rate (%)
- Average Patient Age
- Average Patient Satisfaction Score

**6. Exporting Clean Data**

Exported the cleaned analysis dataset and summary reports into CSV files for further analysis and reporting.
